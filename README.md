# BamTi v0.2 · PS5 밤의 통치자 보조 앱

## 이번 버전에서 추가된 기능
- PS5 16:9 게임 화면 캡처에서 지도 영역 자동 추출(오른쪽 지도 HUD 배치 기준)
- TV를 아이폰으로 촬영한 사진 등은 시작값을 전체 이미지로 설정하고 가로/세로 시작점·크기 슬라이더로 수동 조정
- 지도 크롭 미리보기 및 JPEG 다운로드
- 사진 시드 인식 도구(Nightreign Seed Observer) 연결 링크. 외부 서비스는 **별도로** 이미지를 불러와야 합니다. 외부 Seed Observer는 원본 전체 화면 캡처를 지원하므로 원본을 우선 사용하세요.
- 앱 이름 BamTi, 버전 0.2. 기존 밤비 타이머·성채 수동 기록 유지 (localStorage 키 유지)
- 1일차 타이머 시작 기준 안내 보정: 착지 순간이 아닌 DAY I 시작 효과/기계음 시점

## 제한사항
- 현재 BamTi 자체에는 520개 시드 검색 알고리즘이나 성채 자동 조회 데이터가 없습니다. 사진을 자른다고 시드가 자동 판별되는 것은 아닙니다.
- 오른쪽 지도가 보이는 동일 화면 배치의 16:9 캡처가 자동 자르기 대상입니다. 다른 해상도/TV 사진은 수동 조절하세요.
- PWA가 잠금 화면/백그라운드에서 소리·진동 알림을 실행한다고 보장할 수 없습니다. 타이머 시각은 복귀 시 실제 경과로 갱신됩니다.
- 사진은 서버로 전송하지 않고 JS 캔버스에서 처리합니다. 저장 버튼을 누르면 JPEG가 기기의 다운로드 위치에 만들어집니다.

## 적용 방법 (기존 GitHub Pages BamTi)
1. ZIP 압축을 해제합니다.
2. `index.html`, `manifest.webmanifest`, `icon.svg`, `service-worker.js`, `README.md`를 GitHub `daknichu/BamTi` 저장소 최상위에 업로드하여 **덮어씁니다**.
3. Pages의 main/(root) 설정은 유지합니다.
4. Actions 배포 완료 후 iPhone Safari에서 https://daknichu.github.io/BamTi/ 접속, 재로드하세요. 구형 버전이 남으면 새로고침 또는 Safari 웹사이트 데이터 정리 후 다시 열어보세요(웹사이트 데이터 정리 시 기존 기록이 소실될 수 있습니다).

## 검증
- 예시 입력: 3840×2160 PS5 전체 화면 스크린샷. 지도 영역은 오른쪽 약 x=56.8–95.4%, y=16.0–85.4%입니다.
- 실제 야외 촬영 사진(예: 4:3)에서는 자동 크롭이 맞지 않으므로 전체 이미지로 시작한 후 조정합니다.
- 게임, Bandai Namco, FromSoftware와 무관한 팬 제작 도구입니다.
