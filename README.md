# 밤의 통치자 출격 도우미 v0.1

PS5에서 밤의 통치자를 플레이할 때 아이폰/안드로이드폰의 보조 화면으로 쓰는 프로토타입입니다.

## 현재 구현된 기능
- 1일차/2일차 독립 타이머: 시작, 정지, 재개, ±5초 시간 보정
- 4:30(1차 밤비 시작), 7:30(1차 축소 완료), 11:00(2차 밤비 시작), 약 14:00(밤 보스 전환) 표시
- 4:00/10:30 사전 알림 포함 (앱이 화면에 켜져 있을 때 소리·진동 지원 시 사용)
- 게임 맵 사진 카메라로 촬영 및 로컬 미리보기
- 외부 시드 검색 사이트 열기, 맵 시드 번호/중앙성채 몬스터/지하·옥상 보스 수동 기록
- 사용자의 타이머·성채 메모 로컬 저장, 사진 업로드 없음
- HTTPS 배포 시 홈 화면에 추가 가능한 PWA 및 오프라인 캐시

## 미구현 (추후 개발)
- 사진 자동 인식으로 시드 식별 (520개 패턴 기반 매칭 데이터, 라이선스 검토, iOS 사진 품질 테스트 필요)
- 해당 시드의 중앙성채 수비병/보스 자동 조회
- 앱 비활성화/잠금 화면 상태에서 신뢰할 수 있는 푸시 알림 (iOS는 별도 서버 및 푸시 설정 필요)

## PC에서 시험
1. 폴더에서 `python3 -m http.server 8000` 실행
2. `http://localhost:8000/` 접속

## 아이폰에서 쓰기
- 이 폴더 전체를 GitHub Pages 또는 HTTPS 정적 호스팅에 업로드합니다.
- 아이폰 Safari로 HTTPS 주소를 열고 `공유 > 홈 화면에 추가`를 누릅니다.
- 게임에 착지하는 순간 **출격 시작** 버튼을 누르세요. 맵 사진 촬영은 그 뒤에 해도 타이머가 계속 갑니다.
- 모바일 브라우저는 화면이 꺼진 동안 자바스크립트 실행을 중단할 수 있습니다. 돌아오면 실시간 경과시간으로 정확히 보정되지만, 앱이 꺼져 있을 때의 소리 알림을 보장하지 않습니다.
- 사진은 새로고침/앱 재시작 시 사라집니다. 사진은 업로드/영구저장하지 않습니다.

## 주의
- 소스에 맵 인식·실제 시드 결과가 없어 자동 판별한 척하지 않습니다.
- 외부 시드 데이터와 게임 UI 이미지의 재사용/재배포 조건을 확인하고 기능을 추가해야 합니다.
- 게임 버전별 타이밍과 스테이지 변형은 실측 후 업데이트해야 합니다.
