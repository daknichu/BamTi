# BamTi v0.3 · PS5 밤의 통치자 보조 앱

[앱 열기](https://daknichu.github.io/BamTi/)

1. DAY I 시작음에 맞춰 타이머를 시작합니다. 일시정지, 시간 보정 및 2일차 전환은 v0.2와 같습니다. 잠금 화면에서는 소리 알림이 제한될 수 있습니다.
2. PS5 캡처 또는 TV 사진을 불러옵니다. 16:9 캡처는 오른쪽 지도를 먼저 자릅니다. 슬라이더로 테두리를 맞추고 **이 지도로 시드 찾기**를 누릅니다. JPEG 저장도 가능합니다.
3. 추정 지형과 시설 위치를 확인하고 밤의 왕을 고릅니다. 지도 번호를 누르거나 지점 목록에서 골라 실제 랜드마크를 입력합니다. 잘못 잡힌 시설은 해당 지점에서 ‘미관측’으로 되돌립니다. 사진 없이도 사용할 수 있습니다.
4. 후보가 하나면 **적용 · 성채 조회**를 누릅니다. 이미 아는 시드 번호를 입력해도 수비대·지하·옥상 배정을 조회합니다. 수동 메모와 타이머는 기존 저장 키를 사용합니다. 사진과 관측값은 세션에서만 처리합니다.

## 데이터와 인식 범위

- 사진의 색상·경계 특징과 지도 템플릿을 비교하고 지점 주변의 색상 성분을 찾습니다. 사진 각도, 확대율, 가려진 UI 때문에 틀릴 수 있으며 시설 종류는 직접 지정합니다.
- [Nightreign Seed Observer](https://github.com/stockholm754-source/nightreign-seed-observer/tree/12c51aeaef12329e77b85d9dfee6a19e4b5b15e6)에서 사진 매칭 루틴, 지도 참조 이미지와 시드 스냅샷을 가져왔습니다. 앱에는 축소한 지도와 조회에 필요한 필드만 포함합니다.
- 원본 시드 및 성채 배정은 [Artimuz의 Nightreign Seed Finder](https://nightreign-seed-finder.com/) 자료입니다. 스냅샷 버전 1.03.2, 시드 520개, 성채 배정 390개입니다. 노크라테오와 대공동에는 이 스냅샷의 성채 배정이 없습니다.
- GitHub Pages 또는 로컬 HTTP 서버에서 실행하세요. 서비스 워커 설치가 끝나면 오프라인에서도 조회할 수 있습니다.
