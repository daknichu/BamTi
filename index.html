홈 화면에 BamTi 추가하기

홈 화면에 추가하면 재상영 아이콘을 눌러 BamTi를 바로 열 수 있어요.

아이폰 · Safari
공유(□↑) → 홈 화면에 추가 → ‘웹 앱으로 열기’를 켠 뒤 추가
갤럭시 · Chrome
오른쪽 위 더보기(⋮) → 홈 화면에 추가 → 설치
갤럭시 · 삼성 인터넷
메뉴(☰) → 현재 페이지 추가 → 홈 화면 → 추가

카카오톡 등에서 링크를 열었다면 먼저 Safari나 Chrome, 삼성 인터넷으로 열어 주세요.

사용 통계 설정

접속 국가, 하루 단위 무작위 기기 코드, 앱 버전과 인식 결과를 집계합니다. 첫 분석에서 시드를 확정하지 못한 지도 사진은 분석을 위해 자동 전송됩니다. 사진은 30일, 통계는 90일간 보관합니다.
